N-Queens Problem Solver

About the Project

This project solves the classic N-Queens problem using Python and the Backtracking algorithm.

The goal is to place 8 queens on an 8×8 chessboard so that no two queens attack each other.

Features

- Solves the 8-Queens problem.
- Finds all 92 valid solutions.
- Checks rows, columns, and diagonals.
- Uses Recursion and Backtracking.
- Displays solutions in a chessboard format.

Technologies Used

- Python 3

How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

python main.py

Algorithm

The program uses the Backtracking algorithm to place queens row by row. If a position is unsafe, it tries another column. It stores every valid solution.

Results

The program finds all 92 valid solutions to the 8-Queens problem.
